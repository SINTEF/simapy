   This key-file describes the contents of : dtu10mw_noddis.asc
   The format of dtu10mw_noddis.asc is ASCII
   The file dtu10mw_noddis.asc contains a time series of nodal-displacements
   The nodal-displacements are stored in columns on dtu10mw_noddis.asc

   Column no. 1 contains the time.


   For each node the following applies : 

   DOF 1 = displacement in x - direction
   DOF 2 = displacement in y - direction
   DOF 3 = displacement in z - direction
