
   R I F L E X  -  KEY FILE
   ------------------------


   This key-file describes the contents of : dtu10mw_noddis.bin
   The format of dtu10mw_noddis.bin is BINARY
   with numbers stored as real single precision (4 bytes)
   The file dtu10mw_noddis.bin contains a time series of nodal-displacements
   The nodal-displacements are stored in columns on dtu10mw_noddis.bin

   Column no. 1 contains FORTRAN specific data (please ignore)

   Column no. 2 contains the time.


   For each node the following applies : 

   DOF 1 = displacement in x - direction
   DOF 2 = displacement in y - direction
   DOF 3 = displacement in z - direction


   The response is stored as follows

   Line       Local     Local      No. of         Stored in
    Id        segment   node       responses      column(s)
   ----------------------------------------------------------
 shaft11         1         1           3         3   -      5
 shaft11         1         2           3         6   -      8
 shaft12         1         1           3         9   -     11
 shaft12         1         2           3        12   -     14

   Column no.15 contains FORTRAN specific data (please ignore)
